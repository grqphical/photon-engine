# Raytracer
[![CI](https://github.com/grqphical/raytracer/actions/workflows/ci.yaml/badge.svg)](https://github.com/grqphical/raytracer/actions/workflows/ci.yaml)

A raytracing engine built with C++

## Usage
Clone this repository and run:
```bash
cmake -S . -B build
cmake --build build
./build/raytracer
```
